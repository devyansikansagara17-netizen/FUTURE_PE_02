# AI UGC Video Prompt Generator — Aura Luxe Perfume

## Purpose
This prompt converts a UGC advertisement script into a shot-by-shot filming or AI-video-generation plan. It is intended for a student project about AI Content Marketing Using UGC Ads.

## Copy-and-Use Master Prompt

You are a UGC video production assistant.

Create a detailed shot-by-shot video plan for a short vertical advertisement for Aura Luxe Perfume, a fictional fragrance brand used in an educational project.

**Platform:** Instagram Reels / YouTube Shorts  
**Aspect ratio:** 9:16 vertical  
**Duration:** 15–20 seconds  
**Creator:** A relatable young adult speaking naturally to a smartphone camera  
**Visual style:** Authentic social media footage, clean product close-ups, soft lighting, simple transitions  
**Tone:** Friendly, confident, conversational

Structure the advertisement using these sections:

1. Hook
2. Problem
3. Product introduction
4. Product demonstration
5. Call to action

For every scene, provide:
- Duration in seconds
- Location and background
- Camera angle and framing
- Creator's actions and expressions
- Exact spoken dialogue
- On-screen text
- B-roll or product close-up suggestion
- Transition
- Lighting and mood
- Audio suggestion

The opening should catch attention quickly. Keep the dialogue short and natural. Make the perfume bottle clearly visible. End with a simple CTA.

Do not invent customer testimonials, reviews, ingredients, scent notes, longevity claims, or sales results. If product information has not been supplied, describe only what can be seen.

Return the result as a numbered shot list suitable for editing in Canva.

## Example Scene Prompt
Vertical 9:16 realistic UGC-style video. A relatable young adult creator stands in a bright, uncluttered room and speaks naturally to a smartphone camera while holding a generic perfume bottle. Soft daylight, authentic handheld framing, clear product visibility, no invented brand label, no text baked into the video, no testimonial claims. Leave space for captions.

## Important
This prompt creates a video plan or generation prompt. It does not itself generate an MP4 file. Use a compatible video-generation tool or record/edit clips in Canva to create the final video.
